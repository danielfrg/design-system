# design-system

A design-system for my apps.

There are no components here: Svelte apps use [ui-sdk](https://ui-sdk.dev) components, and this
repo ships the CSS that styles them. There is one version, `public/v1`; it is overwritten in place.

## Usage

Pick a theme from `public/v1` and copy its folder's two files into the app (or list the app in
[`sync.toml`](sync.toml) and run `pnpm sync`, see [Syncing apps](#syncing-apps)), and import them once:

```ts
import "./tokens.css"; // colors, radii, spacing, type, shadows (light and dark)
import "./components.css"; // every @ui-sdk part by data-slot and state, plus the docs'
// layout slots (data-slot="stack", "row", "hint", "card"...)
```

| Theme               | Look                                                                                         |
| ------------------- | -------------------------------------------------------------------------------------------- |
| `public/v1/ui-sdk`  | The ui-sdk docs' own demos: Geist, monochrome, square corners.                               |
| `public/v1/cadence` | Tailwind-flavored: system fonts, cool grays, a blue primary, soft gray borders, 6px corners. |

- Put `@layer ui-sdk;` at the top of the app's global stylesheet, as ui-sdk asks.
- Light/dark follows `color-scheme`. To let people choose, use ui-sdk's
  `createColorScheme({ global: true })`, which writes `data-color-scheme` on `<html>`.
- Load the theme's fonts (Geist and Geist Mono for the ui-sdk theme; Cadence uses system fonts; see `src/index.html`).
- Write markup as the ui-sdk docs examples do, icons included: the styles expect an `<svg>`
  where the examples put one, like a select's chevron or a checkbox's check.
- Restyle from `tokens.css`. Besides colors, the semantic tokens `--fill`, `--fill-hover`,
  `--on-fill` (solid and checked parts) and `--edge`, `--edge-hover`, `--edge-active` (control
  outlines at rest, on hover, and when focused, selected or open) set a theme's character.

The files are generated by `scripts/build-design-css.mjs` (it runs in `pnpm build`) from the
ui-sdk docs' own demo styles. A new theme is a folder in `themes/` with a `tokens.css` (the same
token names as `public/v1/ui-sdk/tokens.css`) and an optional `overrides.css`. The gallery's
theme switch loads the files from `public/v1/<theme>`.

### Custom components

Components ui-sdk doesn't ship live in `public/v1/custom/<name>/`, one folder each (Svelte
components, a stylesheet that reads only `tokens.css`, and an `index.ts`). Copy the folder into
the app, import its stylesheet once, and import the parts from the folder:

```ts
import "./lib/table/table.css";
import { Table, TableHead, sortRows } from "./lib/table";
```

The gallery's "Custom components" section has the demos.

| Component      | What it is                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `table`        | A styled native table with optional sortable headers.                                                                                                                                                                                                                                                                                                                                        |
| `theme-toggle` | An icon button that cycles light, dark and system (the new scheme grows out of the bottom-right corner as a soft circle, via View Transitions; instant with reduced motion), plus the shared `colorScheme` (localStorage key `color-scheme`, so every app agrees). Wrap the app in ui-sdk's `Preferences` and add the `preferencesScript` Vite plugin, as in ui-sdk's "Add Dark Mode" guide. |

### Syncing apps

`sync.toml` lists the apps that use this design system, with the theme and custom components each one
takes. `pnpm sync` copies them into the app's `dest` folder (`theme/` and `custom/<name>/`, wholly
owned by the sync), and `pnpm sync --check` exits 1 if an app has drifted.

```toml
[apps.golinks]
path = "../golinks" # the app's repo, relative to this one
dest = "frontend/src/design-system" # folder owned by the sync
theme = "cadence"
custom = ["table", "theme-toggle"]
```

## Gallery

Showcase for every [ui-sdk](https://ui-sdk.dev) Svelte component (`src/gallery/pages/<id>.svelte`)
plus example pages (`src/examples`). Components use ui-sdk's default `web.css` look for now. The
light/dark/system switch is ui-sdk's `createColorScheme`, saved in `localStorage`.

```bash
pnpm install
pnpm dev      # http://127.0.0.1:5180

pnpm build    # dist/, deployed to GitHub Pages by .github/workflows/pages.yml
```
