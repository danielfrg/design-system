Setup

Paste this in <head>. Tailwind's browser build cannot @import files, so the small tailwind.css theme block has to be inlined. Everything else is linked. 

<html lang="en" data-kit-theme="linear">
<link rel="stylesheet" href="https://danielfrg.github.io/design-system/v1/themes/linear.css">
<link rel="stylesheet" href="https://danielfrg.github.io/design-system/v1/primitives.css">
<style type="text/tailwindcss">
  /* contents of v1/tailwind.css */
</style>
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4.3.5"></script>
<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.17.5/dist/cdn.min.js"></script>

Dark mode: add the dark class to <html>. That is all the tokens need.

Dropdown menu

.dropdown anchors a .menu under its trigger. Use role="menuitemradio" with aria-checked for a choice (the .menu-check shows on the checked item) and role="menuitem" for actions. Alpine handles open, close, arrow keys and Escape.
