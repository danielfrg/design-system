# design-system

Shared design system.

- Many apps share the design based on this design system.
- The files in `public/` are design to be copy pasted into other apps.
- The user might ask to keep these files in sync, you should copy/paste those files into each project, thats how it works for now.

## ui-sdk

- Before using ui-sdk, follow the ui-sdk skill (`.agents/skills/ui-sdk`) and read
  `node_modules/@ui-sdk/svelte/docs/llms.txt`.
- To build a new component, also search `node_modules/@ui-sdk/svelte/docs/core.md` by heading,
  and read `rendering.md` next to it.
- The gallery's component pages render the ui-sdk docs examples vendored in
  `src/gallery/vendor/ui-sdk-examples` (see its README to update them). Don't edit those files.
- `public/v2/<theme>/{tokens,components}.css` are the design system for ui-sdk apps, one folder
  per theme. They are generated by `scripts/build-design-css.mjs` (runs in `pnpm build`): the
  ui-sdk theme from the vendored docs styles, other themes from `themes/<theme>/tokens.css` and
  an optional `overrides.css`. Edit those sources, not the generated files.
